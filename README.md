# 🗓️ Персональное расписание ИТМО 
[![Sync & Deploy ITMO Schedule](https://github.com/volychev/personal-itmo-schedule/actions/workflows/deploy.yml/badge.svg)](https://github.com/volychev/personal-itmo-schedule/actions/workflows/deploy.yml)

Репозиторий для автоматической синхронизации и экспорта расписания занятий Университета ИТМО в формат iCalendar (`.ics`). 
Обновление и публикация календарей выполняются с помощью GitHub Actions и GitHub Pages.

> [!NOTE]
> **Сделано на базе шаблона:** [volychev/itmo-schedule-serverless](https://github.com/volychev/itmo-schedule-serverless)
